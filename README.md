# oh-my-lore

A starter package for an OpenCode and Codex plugin. The package currently has no user-facing functionality; its plugin entrypoints are placeholders while the project takes shape.

## Status

This is an early scaffold. Installing it does not add commands, tools, skills, or other behavior.

## OpenCode

Add `oh-my-lore` to the `plugin` list in your OpenCode configuration. The package exports an empty plugin entrypoint.

## Codex

The root `.codex-plugin/plugin.json` manifest identifies the repository for Codex plugin loading. It currently declares no skills or MCP servers.

## Development

Use Node.js 22 or newer. See [Contributing](CONTRIBUTING.md) for local checks and the release process.
